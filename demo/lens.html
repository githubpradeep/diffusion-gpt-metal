Recurrent depth

Where the answer forms.

One decoder block, 256 wide, applied four times to the same hidden state. The weights are shared, so the only thing that grows with depth is the computation. This page reads the output head off the residual stream after each pass, so you can watch one guess become a committed answer. Every number comes from the Metal kernels on this Mac.

  • parameters —
  • passes — shared block, no extra weights
  • width — hidden size, 4 query heads, 1 key/value head
  • readout tied embedding matrix, no separate head
